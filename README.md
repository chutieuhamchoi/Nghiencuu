# Nghiên cứu

## xsmb/

Trang thống kê tỷ lệ trúng các cách soi cầu XSMB theo thời gian, phục vụ nghiên cứu xác suất thống kê. Đánh lô là vi phạm pháp luật; trang chỉ cung cấp số liệu.

- `index.html`: trang xem số liệu (mở qua GitHub Pages).
- `data/`: số liệu trang đọc: tỷ lệ theo cửa sổ trượt, tổng hợp từng cách, cặp theo từng cách, đề xuất và nhật ký chấm đề xuất.
- `xsmb_analysis.py`: mã tính toán, chạy lại mỗi tối sau giờ quay: `python3 xsmb_analysis.py <ket_qua_xsmb.csv> data`.

Nguồn kết quả: xskt.com.vn.
